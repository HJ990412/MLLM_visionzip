| 방법 | TTFT | 읽기 대기 | GPU 적재 | 워커의 읽기 시간 | hook 시간 | prefill |

읽기 대기 = 요청 스레드가 워커의 읽기를 기다린 벽시계 시간. GPU 적재 = layer별 적재 호출(행과 separator를 GPU cache에 쓰고 mask를 만드는 구간)의 벽시계 합이며, 동기 H2D 복사가 앞선 GPU 연산의 완료를 기다리는 시간이 섞여 있다(두 방식에 같은 정의). hook 시간은 읽기 대기와 GPU 적재를 포함한다. 워커의 읽기는 연산과 겹치므로 이 값들의 합을 TTFT로 해석하지 않는다.
